# Python Flash Servidor minalista para impresiones mediante interfaz web.

Pensado principalmente para aquellas personas que tienen una impresora por cable y comparten con muchas personas la impresora, con esto se busca que el imprimir sea mucho mas facil y agil y se guarde el historial de impresiones.

# Requisitos
* Ser usuario de windows
* Tener una impresora que se conecte por cable
* Tener la impresora como predeterminada para impresion en la maquina servidor

# Características

* Interfaz web amigable para enviar documentos a imprimir
* Impresión directa sin mostrar diálogos o aplicaciones de vista previa
* Soporte para varios formatos de archivo (PDF, DOC, DOCX, TXT, JPG, JPEG, PNG)
* Selección de impresora desde la interfaz
* Historial de trabajos de impresión con seguimiento de estado
* Acceso desde cualquier dispositivo en la red local

# Instalacion
* Abre el cmd / powerShell en la carpeta donde almacena el servidor -> shift + click derecho -> abrir cmd/powershell
* Escribe "python setup.py" para instalar las dependencias
* Una vez instaladas las dependencias escribe en tu terminal "python app.py"
